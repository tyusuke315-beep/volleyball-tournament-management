# バレーボール大会 組み合わせ・日程メーカー

リーグ戦・トーナメントの組み合わせ作成から、日程作成、当日の結果入力、順位表・トーナメント表への自動反映、参加者向けの速報までを1ページで行う大会運営ツールです。

## 画面

| タブ | できること |
|---|---|
| ① 準備 | 大会(リーグ戦・トーナメント)の作成、チーム名入力、組み合わせ、順位表、データの書き出し・共有リンク |
| ② 日程 | 日数・時間・コート数を決めて日程を自動作成。ドラッグで手直し、審判の割り当て、Excel形式コピー、印刷 |
| ③ 結果入力 | 試合ごとにセット数(と任意で得点)を入力。大会別 / 日程順(日ごと)で表示切替、未入力だけの絞り込み |
| ④ 速報 | 順位表・星取表・トーナメント表・日程と結果。閲覧用リンクで参加者に共有 |

## 基本の流れ(例: 4日間)

1. 「＋リーグ戦」でリーグを作り、チーム名を入れる
2. 「＋トーナメント」を作り、「リーグ戦の順位から決める」で上位チームを取り込む
   - 最初は「リーグ1 1位」のように入り、そのリーグの全試合の結果が入ると実際のチーム名に置きかわります
   - 同じリーグのチームどうしが1回戦で当たらないように配置します
3. 「② 日程」で日数を4にし、リーグ戦は「1日目〜2日目」、トーナメントは「3日目〜4日目」にして「日程を作成」
   - トーナメントは回戦ごとに日を指定できます(例: 準決勝・決勝は4日目)
   - 🔒固定 にした大会は、日程を作り直しても動きません(リーグ戦を固定してトーナメントだけ作り直す、など)
4. 当日は「③ 結果入力」でセット数を入力 → 順位表・トーナメント表・日程表に自動反映
5. 「④ 速報」の「閲覧用リンク」を参加者に送る

## 順位の決め方(リーグ戦)

勝数 → セット率 → 得点率 → 直接対決。すべて同じ場合は「同率」と表示され、▲ボタンで手動で入れ替えられます。

## データについて

- 入力内容はブラウザ(localStorage)に自動保存されます
- 「編集用リンク」は運営スタッフ用、「閲覧用リンク」は参加者用です(どちらもリンクを作った時点の内容)
- GitHub Pages で公開すると、スマホの「ホーム画面に追加」でアプリのように使え、電波が弱い会場でも一度開いたページは表示できます

## 公開方法(GitHub Pages)

リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存すると、`https://ユーザー名.github.io/volleyball-tournament-management/` で開けます。
